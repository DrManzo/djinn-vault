## Cover
- Structural model: id (primal drives, pleasure principle), ego (reality principle, mediator), superego (conscience, internalized rules)
- Topographic model: conscious, preconscious, unconscious — the iceberg metaphor
- Psychosexual stages: oral, anal, phallic (Oedipus/Electra complex), latency, genital — fixation at each stage
- All major defense mechanisms: repression, projection, rationalization, sublimation, denial, displacement, reaction formation, intellectualization, regression — each with example
- Dream interpretation: manifest vs latent content, dream work (condensation, displacement, symbolism)
- Transference and countertransference: patient projects onto therapist, therapist's response
- Freudian slips (parapraxis): what they reveal about the unconscious
- What's still used vs what's been debunked: defense mechanisms (still valid in modern psychology), psychosexual stages (largely abandoned), recovered memory therapy (discredited)
