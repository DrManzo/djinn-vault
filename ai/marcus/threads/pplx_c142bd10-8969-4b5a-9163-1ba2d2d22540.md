how do i get this One thing you need to supply: a real firebase-service-account.json in secrets/ before beta_server will fully function. It starts with the placeholder but Firebase calls will fail.
Completed 2 steps

You get it from your Firebase project’s Service Accounts page, then place the downloaded JSON file at secrets/firebase-service-account.json in your project so your beta server can read real admin credentials instead of the placeholder. Firebase says the Admin SDK service account exists automatically for a Firebase project, and you generate a private key JSON from Settings > Service accounts > Generate New Private Key.
firebase.google

Firebase console

Open the Firebase console, choose the correct project, then go to Project settings → Service accounts. Click Generate New Private Key and confirm; Firebase downloads a JSON credentials file that you must store securely.
firebase.google

Put it in your repo

Rename the downloaded file to firebase-service-account.json if your app expects that exact name, then place it in your project’s secrets/ folder so the final path is secrets/firebase-service-account.json. The JSON normally contains fields like type, project_id, private_key_id, private_key, and client_email, which is how you can tell you downloaded the real key and not a stub file.
firebase.google

Important safety

Do not commit that file to GitHub or any public repo, because Google warns that anyone who gets the private key can use the resources that service account can access. Google also notes that once the key file is downloaded, you cannot download that same key again later, so store it carefully; if it leaks, create a new key and delete the old one.
firebase.google

Better deployment option

If beta_server runs on a Google environment like Cloud Run, App Engine, or Cloud Functions, Firebase recommends using Application Default Credentials with initializeApp() and no key file rather than shipping a JSON key file. If you are running locally or on a non-Google server, Firebase says you can either set GOOGLE_APPLICATION_CREDENTIALS to the JSON file path or explicitly pass the key path in code, with the environment-variable approach being the more secure recommendation.
firebase.google

Example

On Linux or macOS, a typical local setup is:

bash
mkdir -p secrets
mv ~/Downloads/your-downloaded-file.json secrets/firebase-service-account.json
export GOOGLE_APPLICATION_CREDENTIALS="$PWD/secrets/firebase-service-account.json"

Firebase documents that GOOGLE_APPLICATION_CREDENTIALS should point to the service account JSON file so the Admin SDK can authenticate in non-Google environments.
