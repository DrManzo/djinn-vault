# Build a 6' x 6' L-Shaped Desk with Metal Hanging Pedestals and Using Elements Parts

## Summary
This note provides instructions for building an L-shaped desk measuring 6' x 6', using metal hanging pedestals, elements parts, and details the associated costs.

## Key Points
- **Worksurfaces**: Two rectangular surfaces; main desk top (72" x 30") and return desk top (72" x 24").
- **Corner Connector**: A corner unit or angle bracket to join the two rectangular surfaces.
- **Support Structure**: Metal hanging pedestals with drawers for storage and structural support, along with U-leg supports.
- **Legs or Frame**: Metal legs or frame supports on the open ends of the desk for stability.
- **Optional Accessories**: Modesty panel for added privacy.

## Details
To build a 6' x 6' L-shaped desk using Elements parts and metal hanging pedestals, follow these steps:

1. **Attach the Two Rectangular Worksurfaces**: Use a corner connector to join the main desk top (72" x 30") and return desk top (72" x 24").
2. **Secure Hanging Pedestals**: Place one pedestal beneath each worksurface at appropriate positions for storage and support.
3. **Install Metal Legs or Frame Supports**: Add U-leg supports on both the main and return desks, along with metal legs or frame supports on the open ends of the desk for stability.
4. **Optional Accessories**: Consider adding a modesty panel to the front of the desk if privacy is needed.
