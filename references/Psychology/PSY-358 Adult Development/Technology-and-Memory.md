Memory and technology have a complex relationship, with recent research suggesting that digital devices can actually enhance memory skills rather than hinder them. Contrary to concerns about "digital dementia," studies indicate that smartphones and other digital devices can serve as effective external memory tools, potentially improving both stored and unstored information recall.

A study published in the Journal of Experimental Psychology: General demonstrated that using digital devices as external memory aids not only helps people remember saved information but also improves recall of unsaved information (Gilbert et al., 2022). The researchers found that participants who used digital reminders showed an 18% improvement in memory for high-value information and a 27% improvement for low-value information, even when they hadn't set reminders for the latter. This suggests that offloading important information to devices allows individuals to allocate more cognitive resources to less critical information, enhancing overall memory performance (Gilbert et al., 2022).

However, it's important to note that reliance on technology for memory support is not without potential drawbacks. Cavanaugh (2024) points out that while external aids can be beneficial, overreliance may lead to a reduction in the effortful processing required for long-term memory formation. Current research aligns with the idea that technology can be a valuable tool for memory enhancement when used judiciously. For instance, smartphone apps designed for cognitive training and memory exercises have shown promise in improving memory function, particularly in older adults (Klimova, 2019). These findings suggest that technology, when used as a supplement to, rather than a replacement for, cognitive effort, can contribute positively to memory maintenance and improvement across the lifespan.
