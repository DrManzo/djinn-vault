# Working Memory

## Summary
Working memory is the brain's active processing workspace, temporarily holding and manipulating information for complex cognitive tasks. Unlike simple short-term storage, working memory involves active control, limited capacity, and domain-specific subsystems that determine how effectively we reason, learn, and solve problems.

## Key Points
- Working memory has limited capacity (~4 chunks) and requires active maintenance; information decays rapidly without rehearsal or attention
- Baddeley's model includes four components: the central executive (attentional control), the phonological loop (verbal information), the visuospatial sketchpad (visual-spatial information), and the episodic buffer (integration hub)
- The phonological loop consists of the phonological store (holding verbal information for ~2 seconds) and the articulatory rehearsal process (refreshing information through subvocal rehearsal)
- The visuospatial sketchpad handles visual imagery and spatial navigation, with evidence suggesting separate visual and spatial subcomponents
- The episodic buffer integrates information from the subsystems and long-term memory into coherent episodes, explaining how we experience unified conscious awareness
- Working memory capacity is a stronger predictor of academic performance than IQ; deficits in working memory underlie many learning difficulties including ADHD and dyslexia

## Details
Working memory constraints have practical implications for learning and professional practice. Cognitive load theory suggests that instructional design should minimize extraneous load (unnecessary complexity) while managing intrinsic load (complexity inherent to the material). Chunking strategies—grouping information into meaningful units—effectively expand working memory capacity.

The central executive functions as an attentional control system, not a storage buffer. It coordinates the subsystems, switches between tasks, inhibits irrelevant information, and updates working memory contents. Individual differences in executive function largely explain variations in working memory capacity and cognitive performance.
