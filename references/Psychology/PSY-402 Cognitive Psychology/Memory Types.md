# Memory Types

## Summary
Human memory consists of four distinct systems that differ in duration, capacity, and level of conscious awareness: sensory memory (fleeting buffer), short-term/working memory (active manipulation), nondeclarative memory (unconscious skills and habits), and declarative memory (conscious facts and events). Understanding these systems explains how information is encoded, stored, and retrieved.

## Key Points
- Sensory memory acts as a fleeting buffer holding incoming sensory information for milliseconds to seconds; iconic (visual) memory lasts ~300-500ms, echoic (auditory) memory lasts up to 10 seconds
- Short-term/working memory maintains information for seconds to minutes with limited capacity (~4 chunks); it requires active conscious attention and involves manipulation of information
- Nondeclarative (implicit) memory consists of skills, habits, and conditioned responses expressed through performance rather than conscious recollection; relies on basal ganglia and cerebellum
- Declarative (explicit) memory involves conscious storage and retrieval of facts (semantic) and events (episodic); heavily dependent on the medial temporal lobe and hippocampus
- The dissociation between memory types is clinically evident in Alzheimer's disease, which disproportionately devastates episodic memory while procedural skills often remain intact
- Memory systems are interconnected: sensory memory feeds working memory, which can encode into long-term declarative or nondeclarative systems depending on the nature of processing

## Details
Real-life examples illustrate each system: the sparkler trail effect demonstrates iconic sensory memory; calculating a tip in your head engages working memory; riding a bicycle after years without practice shows nondeclarative procedural memory; recalling your last birthday exemplifies declarative episodic memory.

The distinction between declarative and nondeclarative memory is critical for understanding neurodegenerative conditions. Alzheimer's disease attacks the hippocampus early, devastating episodic memory, but because nondeclarative memory relies on extra-hippocampal structures, patients often retain procedural skills long after their ability to recall recent events vanishes.
