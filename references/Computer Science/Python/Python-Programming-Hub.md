## Summary
Central reference hub for Python programming topics covering text processing, GUI development with PyQt6, web development with Django, and game development focusing on creating a Tetris-like game. Each note documents specific techniques, architectures, and best practices derived from Perplexity AI chat exports.

## Topics

### Text Processing & Document Generation
- [[Scrambled Notes to APA Essay Converter]] - Pipeline for converting unstructured notes into APA-formatted Word documents using `python-docx`, with automatic sentence normalization, paragraph grouping, and transition insertion.

### GUI Development
- [[PyQt6 Modular UI Architecture]] - Modular programming patterns for PyQt6 desktop applications, demonstrated through the "Notation Clark" reference card system with 8-file separation of concerns.

### Web Development
- [[Django Template Conversion Guide]] - Converting static HTML into production-ready Django templates with template inheritance, dynamic data binding, static file organization, and MVT architecture.

### Game Development
- **Building a Tetris Game in Python** - Resources and guides for creating a text-based game in Python, focusing on fundamental programming concepts such as functions, user input handling, conditional statements, string manipulation, data structures, and loops.

## Cross-References
- All projects use Python 3.14+ with explicit imports and documentation.
- Modular design principles apply across GUI, web, script-based, and game development projects.
- Separation of concerns is a recurring theme (styles.py, models vs views, pipeline stages).
