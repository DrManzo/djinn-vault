## How the Agent Loop Now Works

```
Javier or Claude writes to COMMS.md → @Salomon or @Typhon
        ↓ (vault-sync pushes in 2 min)
comms-processor timer fires (every 3 min)
        ↓
Script detects new entries for this agent
        ↓
opencode run -m ollama/qwen2.5:7b -f SOUL.md -f AGENTS.md "[task]"
        ↓
opencode executes (file ops, shell, search)
        ↓
Response appended to COMMS.md → vault push
        ↓
Other agents see the response on next sync
```
