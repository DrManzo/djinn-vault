What NUNO-Djinn Is

NUNO-Djinn is a full-stack Flutter-based messenger app (think a self-hosted Signal/WhatsApp clone) with the client named nuno_client . The nuno_client is a Flutter app targeting iOS, Android, Web, macOS, Linux, and Windows simultaneously . The backend is two Java Spring Boot servers (a REST API server on port 8080 and a WebSocket messaging server on port 8000) plus PostgreSQL, all orchestrated with Docker Compose .

What You Need to Do to Build for iPhone
Step 1 — Prerequisites (Mac Required)

You must have a Mac with Xcode to build an iOS .ipa. There is no way around this — Apple mandates it. You need:

Xcode 16+ (for Flutter SDK ^3.5.4)

Flutter SDK 3.5.4 or higher

CocoaPods (sudo gem install cocoapods)

An Apple Developer account (free for TestFlight/personal device, $99/year for App Store)

Step 2 — Fix the Server URLs (Critical Blocker)

Right now assets/config.json points the API and WebSocket hosts to a local IP 192.168.1.225 . Your iPhone cannot reach that from outside your LAN. You need to:

json
{
  "apiHost": "https://your-server-domain.com",
  "messagingHost": "wss://your-server-domain.com/ws"
}

Either deploy the Docker stack to a VPS/cloud (DigitalOcean, Render, Railway, etc.) or expose it via a tunnel like Ngrok for testing. The app won't function otherwise.

Step 3 — Configure Signing in Xcode
bash
cd nuno_client
flutter pub get
cd ios
pod install

Then open ios/Runner.xcworkspace in Xcode, go to Signing & Capabilities, select your Apple team/Developer Account, and let Xcode auto-manage the provisioning profile. The bundle ID is com.nuno.client .

Step 4 — Build and Deploy

For a physical iPhone (without App Store):

bash
# Connect iPhone via USB
cd nuno_client
flutter build ios --release
flutter run --release

Or build an .ipa archive in Xcode → Product → Archive → Distribute App → Ad Hoc / Development.

For TestFlight (share with testers):

bash
flutter build ipa

Then upload via Xcode Organizer or xcrun altool.
