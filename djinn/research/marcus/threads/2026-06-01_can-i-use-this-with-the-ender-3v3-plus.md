# Can I use this with the Ender 3v3 plus?

Yes — the Ender-3 V3 Plus supports common filaments like PLA, TPU, PETG, ABS, and PLA-CF, and Creality’s own documentation shows it uses Creality Print and Orca Slicer workflows, with Klipper-based firmware and a direct-drive setup.

What it supports

Creality lists the Ender-3 V3 Plus as supporting PLA, TPU, PETG, ABS, PLA-CF, PETG-CF, and CR-Carbon. It also has a 300 x 300 x 330 mm build volume and a heated bed, which makes it suitable for larger prints and higher-temperature materials like ABS with an enclosure recommended.

If you’re asking about a multi-color system like Creality CFS, compatibility is not clearly confirmed in the official sources I found, and community posts suggest it has been discussed as a future upgrade rather than a guaranteed current option.
