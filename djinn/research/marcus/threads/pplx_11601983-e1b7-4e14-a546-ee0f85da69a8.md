Clarifying the intended use of “local”

Yes — this setup is local on your machine. The Docker container runs on your own computer, and Moonraker is exposed on localhost:7125, so the virtual printer stays on your system unless you deliberately open ports or reverse-proxy it.

Local behavior

The compose file maps only your machine’s local ports to the container: 7125:7125 for Moonraker and 8110:8080 for the dummy webcam stream, with printer data stored in a local ./printer_data folder. That means your config, uploaded G-code, logs, and simulated printer state all live on disk on your computer, not in a cloud service.

Mainsail access

If you use my.mainsail.xyz, the web app itself is hosted remotely, but it connects to your local Moonraker instance that you point it to, such as localhost:7125. If you want everything local, you can also host Mainsail yourself instead of using the hosted frontend, so both the UI and the printer backend stay entirely on your machine.
