Here's your Djinn Dice Scanner app, Javier. Here's what it does:

Features

📸 Image Capture

Live camera — hits your device's rear-facing cam directly from the browser, lets you frame the shot and tap Capture

Upload / drag-and-drop — works with any photo from your gallery or filesystem

Falls back to upload-only if camera permission is denied

🎲 Dice Detection
The app runs a real canvas-based computer vision pass on the captured image — it converts the image to grayscale, applies adaptive thresholding, runs connected-component blob detection for pips (dots), then clusters blobs spatially to identify individual dice and their face values. It works best with:

Flat, well-lit surface (white/cream background)

Dice spread out without overlapping

Standard pip dice (d4, d6, d8, d10, d12, d20)

Manual override always available — if detection misses a die or reads a value wrong, you can add/remove dice individually with the manual row at the bottom of the pool.

⚔️ D&D Stat Assignment

Click dice in the pool to select them (they highlight + running total shows)

Hit Assign next to STR / DEX / CON / INT / WIS / CHA to apply

Auto-Assign drops the highest values top-down (STR first)

Modifier is auto-calculated and color-coded (green = positive, red = negative)

Export Sheet downloads a clean .txt stat block

Notes for Djinn Integration

Since this is a static HTML app, you can drop the file directly into the Djinn project's frontend or serve it as a tool panel. The vision logic is in the detectDiceFromCanvas() function — you could swap that out with a call to a local Ollama vision model (LLaVA, MiniCPM-V) via a Python backend endpoint for much higher accuracy when you're ready to extend it.
