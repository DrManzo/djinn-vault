## How to Add a New Post

1. Drop file(s) in **#media-inbox** on Discord, or run:
   ```
   djinn-media-ingest <path>
   ```
2. Djinn creates a folder at `~/Obsidian/djinn/media/posts/<project_id>/`
3. Pipeline runs: edit → caption → thumbnail → QA → publish-prep
4. Finished package appears in **#post-ready** on Discord
5. Copy caption + hashtags, upload files, post

**Update this index manually** when a post goes live — add the date posted and move from Active → Completed.
