# Are There Apps on Apple Store That Help Learn Shorthand Techniques?

## Summary
There are a few apps available on the Apple App Store that can help with learning shorthand techniques, though options are somewhat limited.

## Key Points
- **iStenoPad**: Designed for practicing stenography on an iPad. Features include real-time translation, customizable key styles, and speed tracking.
- **Anki**: A flashcard app used by some users to study various shorthand systems like Pitman and Teeline.
- **Stenotation**: Released in 2023, allows custom text input at different speeds but is not specifically for learning shorthand.

## Details
iStenoPad offers several features that can be beneficial for learning shorthand:
- Writing steno using the iPad's touch-screen
- Instant real-time translation
- Importable and pre-loaded translation dictionaries
- Customizable key styles, text sizes, and colors

However, it lacks tactile feedback, making proper finger orientation challenging. Some users report issues with accurate word identification.

Anki is a flashcard app that can be used to study shorthand systems but is not specifically designed for learning shorthand.

Stenotation allows creating custom dictations at various speeds, useful for practice but not focused on teaching shorthand techniques.
