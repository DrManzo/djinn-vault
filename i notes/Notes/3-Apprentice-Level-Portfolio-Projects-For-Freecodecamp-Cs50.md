# 3 Apprentice-Level Portfolio Projects for FreeCodeCamp, CS50, and Web Security Academy

## Summary
This note outlines three apprentice-level portfolio projects that align with the freeCodeCamp, CS50, and Web Security Academy frameworks. Each project builds progressively to showcase a range of programming skills.

## Key Points
- Personal Finance Dashboard (Python + Web Dev)
- Secure Authentication System (C# or VB.NET + Cybersecurity)
- Network Traffic Analyzer (Python + Cybersecurity)

## Details

### Project 1: Personal Finance Dashboard (Python + Web Dev)
**Core Framework:** freeCodeCamp Python Programming + CS50 Web Track
**Tech Stack:**
- Backend: Python with Flask/Django
- Frontend: HTML, CSS, JavaScript (from freeCodeCamp Responsive Web Design)
- Database: SQLite or PostgreSQL (CS50 databases)
- Data Visualization: Chart.js or Plotly

**Key Features:**
- User authentication (login/register)
- Add/edit/delete transactions
- Category-based expense breakdown
- Monthly budget tracking with alerts
- Visual charts showing spending trends

### Project 2: Secure Authentication System with Vulnerability Testing (C# or VB.NET + Cybersecurity)
**Core Framework:** CS50 + Web Security Academy (Server-Side Vulnerabilities Path)
**Tech Stack:**
- Backend: C# with ASP.NET or VB.NET
- Database: SQL Server or MySQL
- Testing Tools: Burp Suite, OWASP ZAP
- Documentation: Markdown report of vulnerabilities found/fixed

**Key Features:**
- User registration with password hashing (bcrypt)
- Session management
- Input validation to prevent SQL injection
- Protection against XSS and CSRF attacks
- Security audit report documenting vulnerabilities you fixed

### Project 3: Network Traffic Analyzer (Python + Cybersecurity)
**Core Framework:** Python + Web Security Academy + CS50
**Tech Stack:**
- Capture network packets using libraries like Scapy or PyShark
- Analyze packet data for security insights
- Visualize traffic patterns with Matplotlib
