# Building a Tetris Game in Python

## Summary
This note provides resources and guides for building a text-based game in Python, specifically focusing on the creation of a Tetris-like game.

## Key Points
- **Books**: 
  - *Learn Python 3 the Hard Way* by Zed Shaw includes basic game development.
  - *Invent Your Own Computer Games with Python* (4th Edition) by No Starch Press focuses on game creation.
  - *Make Your Own Text Adventure With Python* is dedicated to text adventure games.

- **Online Tutorials**:
  - Python Text Adventure Tutorial: Comprehensive walkthrough for creating a text adventure.
  - GitHub Text-Adventure-Tutorial: Structured project with clear phases covering variables, functions, and story formatting.

## Details
Building a text-based game in Python can be an excellent way to learn fundamental programming concepts such as functions, user input handling, conditional statements, string manipulation, data structures, and loops. Here are some resources that will guide you through the process:

### Books with Text Game Walkthroughs

1. **Learn Python 3 the Hard Way** by Zed Shaw
   - This book includes a text adventure game project earlier in the book.
   - It covers basic game development concepts and is suitable for beginners.

2. **Invent Your Own Computer Games with Python** (4th Edition) by No Starch Press
   - Focuses on teaching users to combine loops, variables, and flow control statements into real working programs.
   - Specifically includes a section on game creation.

3. **Make Your Own Text Adventure With Python**
   - Available on Leanpub.
   - Dedicated to text adventure game creation.

### Free Online Tutorials

1. **Python Text Adventure Tutorial** (python-text-adventure.readthedocs.io)
   - Comprehensive walkthrough for creating a text adventure.
   - Uses a free online environment, so no installation is required.

2. **GitHub Text-Adventure-Tutorial** by Kyle-L
   - Structured starter project with clear phases covering variables, functions, and story formatting specifically for adventure games.
   - Breaks down the game flow: start at page 1, read content, make choices, navigate to new pages based on choices, and repeat until the end.

### What You'll Learn

- Functions
- User input handling with `input()`
- Conditional statements (`if`, `elif`, `else`)
- String manipulation with methods like `lower()`
- Data structures (lists and dictionaries for inventory/items)
- Loops for game flow
