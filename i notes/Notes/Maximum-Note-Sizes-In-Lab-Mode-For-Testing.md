# Maximum Note Sizes in Lab Mode for Testing Purposes

## Summary
This note provides an analysis of the maximum sizes and capacities of notes that can be generated using Perplexity's lab mode, focusing on testing purposes.

## Key Points
- Standard queries allow up to 8,000 tokens (~20,000 characters) per note or message.
- File uploads support up to 40 MB each with a maximum of 10 files at once.
- Max and Enterprise Max plans offer virtually unlimited queries but maintain the token processing cap.

## Details
For testing purposes in Perplexity Labs mode:

- **Token Processing Cap**: Up to 8,000 tokens (~20,000 characters) per query. This limit applies both to text inputs and file uploads.
- **File Uploads**: Each file can be up to 50 MB with a maximum of 30 files attached simultaneously during an analysis task. Standard users can upload up to 10 files (40 MB each), while Max and Enterprise Max plans offer higher limits.
- **Data Formats Supported**: Markdown (.md), PDF, DOCX, CSV, TXT, JSON, and other structured text or dataset files.

When running a full analytical study:

- **Input Limits**: Each file can be up to 50 MB with batch uploads of 30–50 files. Standard users handle up to 10 files (40 MB each), while Max and Enterprise Max plans offer enhanced limits.
- **Output Scale**: Comprehensive summaries with over 100+ citations are possible in Research or Enterprise Max mode. Lab sessions can last up to 30 minutes for large, multi-source synthesis projects.
- **Token Constraints**: Each generation caps at about 8,000 tokens (~20,000 characters) per response block. Longer analyses are segmented into continued outputs.
