# Ender 3 V3 Plus Issue 3343 Troubleshooting

## Summary
This note provides troubleshooting steps for the "Issue 3343" reported on an Ender 3 V3 Plus printer, focusing on mechanical and setup issues.

## Key Points
- **Mechanical/Setup Problem or Firmware/Calibration Fault**
- **Fast Checks:**
  - Re-run self-calibration on a stable surface.
  - Check all visible connectors (especially head/home/limit switch wiring).
  - Factory reset and re-calibrate if issue started after firmware update.

## Details
If the printer is showing an error or failing to print, inspect for bed adhesion issues, hotend clogs, or extrusion jams. Common causes include:
- **Bed Adhesion Problems**
- **Hotend Jams**

For more detailed troubleshooting, send the exact message on the printer screen and whether it occurs during homing, leveling, or printing.
