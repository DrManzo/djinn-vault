# Fedora Workstation IDE Recommendations for AI Development

## Summary
The note provides recommendations for Integrated Development Environments (IDEs) suitable for working with AI on a Fedora workstation, focusing on PyCharm and Visual Studio Code.

## Key Points
- **Visual Studio Code** or **VSCodium**: Good for general coding needs.
  - Popular among Linux users due to its extensions, debugging capabilities, Git integration, and performance.
  - Install via RPM from Microsoft, Flatpak from Flathub, or `dnf`.
- **PyCharm**: Best choice if working primarily with Python and AI model code.
  - Strong debugging, test discovery, virtual environments, and project navigation features are beneficial for maintaining testable and maintainable code.

## Details
For Fedora Workstation users interested in AI development, the following IDEs are recommended based on their specific needs:

- **Visual Studio Code (VS Code) or VSCodium**: These editors are highly versatile and can handle a wide range of programming languages including Python, C/C++, Rust, and more. They offer robust debugging tools, Git integration, and a large number of extensions that can be installed via Open VSX or side-loading `.vsix` files.

- **PyCharm**: Ideal for those primarily working with Python and AI model code. PyCharm provides comprehensive support for unit testing, test module placement, and direct integration within the full Python IDE environment. This is crucial when transitioning from basic functionality to more rigorous testing and maintainability.
