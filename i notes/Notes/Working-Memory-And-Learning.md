# Working Memory and Learning

## Summary
Working memory is a cognitive system that temporarily holds and manipulates information, crucial for complex cognition. It functions as a bottleneck in human processing, significantly impacting learning and intelligence.

## Key Points
- Working memory retains 3-4 meaningful units of information.
- Contemporary research suggests working memory capacity is about 4±1 chunks.
- Working memory is essential for learning and problem-solving tasks.

## Details
Working memory serves as the cognitive architecture's central workspace—a limited-capacity system that temporarily holds and manipulates information. This mental "scratchpad" functions as a critical gateway through which all learning must pass, demonstrating profound connections to human intelligence. Modern cognitive neuroscience defines working memory as the retention of a small amount of information in a readily accessible form, with contemporary research by Nelson Cowan revealing that the true capacity of attention-based working memory approaches 4±1 chunks when strategic processes like rehearsal are controlled.
