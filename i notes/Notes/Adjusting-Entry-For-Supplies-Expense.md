# Adjusting Entry for Supplies Expense

## Summary
This note details the adjusting entry required to record the use of supplies during a fiscal period, ensuring accurate financial statements.

## Key Points
- **Supplies Used Calculation**: $8,800 (initial balance) - $1,100 (end-of-period inventory) = $7,700.
- **Journal Entry**:
  - Debit: Supplies Expense $7,700
  - Credit: Supplies $7,700

## Details
The adjusting entry for supplies is crucial to ensure that the financial statements reflect accurate figures. Here’s a step-by-step breakdown:

1. **Initial Balance and Calculation**: At the beginning of the period, the trial balance shows Supplies at $8,800. By December 31st, there are only $1,100 worth of supplies on hand. Therefore, the amount used during the period is calculated as follows:
   - \( \text{Supplies Used} = \$8,800 - \$1,100 = \$7,700 \)

2. **Journal Entry**:
   - Debit: Supplies Expense $7,700
     - This entry increases the expense account to reflect the cost of supplies used during the period.
   - Credit: Supplies $7,700
     - This reduces the asset account to match the physical count of remaining supplies.

3. **T-Accounts**:
   - **Supplies (Asset Account)**:
     ```
     Supplies
     ________________________________
     | Debit  | Credit |
     |--------|--------|
     | Bal. \$8,800 | |
     | | Adj. \$7,700 |
     |--------------|----------|
     | Adj. Bal. | |
     | \$1,100 | |
     ```
   - **Supplies Expense (Expense Account)**:
     ```
     Supplies Expense
     ________________________________
     | Debit  | Credit |
     |--------|--------|
     | Bal. \$0 | |
     | Adj. \$7,700 | |
     |--------------|----------|
     | Adj. Bal. | |
     | \$7,700 | |
     ```

4. **Quick Snapshot**:
   - **Supplies (Asset)**
     ```
     Account  | Unadjusted Balance | Adjustment | Adjusted Balance
     -------- | ------------------ | ---------- | ---------------
     Supplies | \$8,800 Dr         | \$7,700 Cr | \$1,100 Dr
     ```

   - **Supplies Expense**
     ```
     Account  | Unadjusted Balance | Adjustment | Adjusted Balance
     -------- | ------------------ | ---------- | ---------------
     Supplies Expense | \$0                | \$7,700 Dr | \$7,700 Dr
     ```
