# THC-Based D&D 5E System

## Summary
A fully functional D&D 5E system that uses THC products as ability points and hit points, with unique classes and races.

## Key Points
- **Base Level**: Five
- **Classes**:
  - Barbarian: Edibles/Gummies (5mg each)
  - Bard: Drinkables/Shots (10mg each)
  - Druid: Flowers/Hits (5-10mg each)
  - Fighter: Gummies
  - Cleric: Mixed products
  - Wizard/Warlock: Wax Concentrates (dabs) - precision, potent
- **Races**:
  - Human Naturalist (+2 HP, flexible)
  - Elf Refined (+1 HP, wax specialty)
  - Dwarf Hearty (+3 HP, heavy tolerance)
  - Halfling Quick (+1 HP, quick recharge)
  - Dragonborn Potent (+5 HP, universal products)
- **Mechanics**:
  - Double Take Option: Consume extra THC for advantage on failed checks
  - Penalty Pass Option: Skip consumption, give enemies advantage instead
  - Token/Candy System: Use instead of actual THC (same mechanics)

## Details
The system is designed to be as simple as possible while maintaining all standard D&D 5E mechanics. It includes a complete set of rules and character sheets for five classes and five races, with integrated THC rules. The system also features safety protocols, dosing guidelines, and common questions answered.

### Key Features
- **Class-Specific THC Products**:
  - Barbarian: Edibles/Gummies (5mg each) - aggressive, sustained
  - Bard: Drinkables/Shots (10mg each) - social, shareable
  - Druid: Flowers/Hits (5-10mg each) - natural, elemental
  - Cleric: Mixed products - flexible, balanced
  - Fighter: Gummies - disciplined, tactical

- **Races**:
  - Human Naturalist (+2 HP, flexible)
  - Elf Refined (+1 HP, wax specialty)
  - Dwarf Hearty (+3 HP, heavy tolerance)
  - Halfling Quick (+1 HP, quick recharge)
  - Dragonborn Potent (+5 HP, universal products)

- **Optional Rules**:
  - Double Take Option: Consume extra THC for advantage on failed checks
  - Penalty Pass Option: Skip consumption, give enemies advantage instead

- **Safety First**:
  - Adult-only (21+)
  - Consent required
  - Designated sober monitor
  - Medical awareness
  - Stop-anytime protocol

### How to Use
- **For DMs**:
  - Read Complete guide (45-90 min)
  - Print or share character sheets
  - Run Session 0 (character creation)
  - Run Sessions 1+ with built-in pacing

- **For Players**:
  - Pick class from 5 available
  - Get one-page character sheet
  - Fill in 15-20 minutes
  - Ready to play

### First Session
- 15 min: Safety/rules
- 90 min: Character creation
- Players ready to go
