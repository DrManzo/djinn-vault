# Make a Script to Write to My iPhone and Make It Do Things via Siri

## Summary
This note outlines how to create automations on an iPhone using the Shortcuts app, which can be triggered by Siri. The process involves creating specific shortcuts for various tasks and setting up automatic triggers.

## Key Points
- **Shortcuts App**: Use this app to build automations that can perform actions like opening apps, sending messages, or controlling smart home devices.
- **Siri Triggers**: You can trigger these automations by saying their names out loud or through certain automatic triggers (e.g., time of day).
- **Automation Setup**: Create a shortcut and name it for Siri. Optionally, set up personal automations to run automatically based on specific events.

## Details
To create an automation that can be triggered by Siri:

1. **Open the Shortcuts App**:
   - Launch the app from your iPhone’s home screen.
   
2. **Create a New Shortcut**:
   - Tap the "+" button in the top right corner to start creating a new shortcut.
   - Add actions such as opening an app, sending a message, or setting a timer.

3. **Name It for Siri**:
   - Give your shortcut a simple name like "Study Mode" or "Workout Start".
   - This name will be used when you trigger the automation with Siri.

4. **Set Up Automatic Triggers (Optional)**:
   - Go to the Automation tab in Shortcuts.
   - Create a personal automation by tapping “Create Personal Automation”.
   - Choose a trigger, such as time of day or connecting to Wi-Fi.
   - Add the same actions from your shortcut and turn off "Ask Before Running" where allowed.

Example: A "Focus & Tools" shortcut that:
- Turns on Do Not Disturb.
- Opens your study/to-do app.
- Starts a 25-minute timer.

You can then trigger it with “Hey Siri, Focus & Tools.”
