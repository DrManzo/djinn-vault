# Preparing Your Ender 3 V3 Plus for Printing

## Summary
This note provides a guide on preparing your new Ender 3 V3 Plus printer and filament before starting your first print.

## Key Points
- Clean the build plate thoroughly.
- Level the bed properly.
- Adjust Z-offset for optimal first layer squish.
- Use adhesives like glue stick or hair spray if needed.
- Ensure filament is dry, especially if it's been opened or stored without desiccant.
- Set appropriate bed temperature based on filament type.

## Details
For your new Ender 3 V3 Plus, preparing the printer and filament correctly ensures successful prints. Here’s a step-by-step guide:

1. **Clean the Build Plate**
   - Use isopropyl alcohol (70% or higher) to remove any oils, dust, or residue from manufacturing.
   - Clean the build plate thoroughly before adding any adhesives.

2. **Level the Bed**
   - Proper bed leveling is essential for uniform first layers and good adhesion.
   - Ensure the nozzle is at the correct height from the bed for optimal first layer squish.

3. **Adjust Z-Offset**
   - Set the Z-offset in your slicer software to ensure the nozzle is correctly positioned above the build plate.

4. **Add Adhesives (if needed)**
   - Use adhesion helpers like glue stick or hair spray if you're experiencing adhesion issues.
     - **Glue Stick** (like Elmer's): Apply a thin, even layer for extra adhesion, especially useful for PLA and PETG.
     - **Hair Spray**: Another popular option that can be sprayed in a thin coat.

5. **Ensure Filament is Dry**
   - Check the filament type: It’s PLA, but the spool says PETG, which might cause issues if not properly dried.
   - Ensure the filament is dry before printing, especially if it's been opened or stored without desiccant.

6. **Set Appropriate Bed Temperature**
   - Set your bed temperature based on the filament type:
     - 50-60°C for PLA
     - 80-90°C for PETG

If you still experience adhesion issues after cleaning and leveling, enable a brim in your slicer software to increase the contact area with the bed.
