# HERMES Model Framework

## Summary
The HERMES model is a comprehensive Swiss project management methodology providing structured phases, milestones, scenarios, and roles for managing complex projects. It emphasizes outcome-oriented delivery with adaptable scenarios tailored to different project types and complexities.

## Key Points
- HERMES is structured around four main phases: Initialization, Concept, Realization, and Implementation, with an optional fifth Completion phase in HERMES 5
- Each phase contains predefined milestones that serve as quality gates to assess project status at critical lifecycle points
- Scenarios are tailored templates for different project types that leaders can select, adapt, and share for validation
- Modules are reusable components grouping related tasks, results, and roles to facilitate efficient scenario creation
- Defined roles include Client (governance/sustainability), Project Leader (planning/management), and Technical Specialist (execution)
- The model uses a results-oriented approach where every task is directly linked to specific deliverable outcomes
- A structured data model ensures coherence across method components for effective data handling throughout the project lifecycle
- HERMES is outcome-oriented rather than process-oriented, encouraging iterative development and continuous improvement
- The framework supports risk management through milestone quality gates and scenario-based planning
- Standard scenarios can be modified and shared among users for organizational validation and reuse
- Roles are assigned to hierarchical levels within the project structure with clear responsibility boundaries
- The methodology is designed for managing complex projects across government, enterprise, and technology domains

## Details
The HERMES model originated as a Swiss federal standard for IT project management and has evolved into a general-purpose project management framework. Its modular architecture allows organizations to tailor the methodology to their specific needs while maintaining consistency through shared scenarios and modules.

The data model provides a structured framework connecting all method components — phases, milestones, scenarios, modules, roles, tasks, and results — into a coherent system. This ensures that project managers can trace every activity back to a defined outcome.

The framework's emphasis on adaptability means it can be applied to projects ranging from small internal initiatives to large-scale government programs. The scenario-based approach is particularly valuable for organizations that run similar project types repeatedly, as proven configurations can be standardized and reused.
