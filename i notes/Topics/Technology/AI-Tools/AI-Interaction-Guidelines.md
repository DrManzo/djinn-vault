# AI Interaction Guidelines

## Summary
Structured guidelines and prompt templates for configuring AI agents to answer multiple-choice questions with high accuracy, using only provided resources and options. Includes the "Leave it as is" protocol for constraining AI responses, verification procedures, and example interactions for educational assessment workflows on the Sophia Learning platform.

## Key Points
- AI agents must answer strictly using only the options provided in the user's questions
- The phrase "Leave it as is" instructs the AI to provide no additional commentary or external resources
- Responses should use only files and resources attached to the workspace, avoiding online or web sources
- Each option must be carefully evaluated before selecting the answer that best fits the question
- Target accuracy is 75% minimum with 100% being preferable through double and triple-checking
- Responses must be clear, concise, informative, logical, actionable, and engaging
- The AI should not add any additional information or context outside of the given options
- If uncertain, the AI should prioritize clarity and relevance when selecting among provided options
- A feedback loop encourages users to provide feedback on responses to improve future accuracy
- Example interaction format: User provides question with options A-D, AI responds with the correct letter and answer text only
- These guidelines were developed for Sophia Learning coursework covering accounting, finance, and business subjects
- The protocol ensures consistency when transferring work between different AI agents or Perplexity spaces
- Structured responses should follow the pattern: "The correct answer is [Letter].) [Answer text]."
- Resource utilization must be confined to attached files; external web searches are explicitly prohibited during assessment
- The guidelines support multi-subject coverage including accounting ethics, governance, trial balances, and financial ratios

## Details
The AI interaction framework was designed to address a specific need: ensuring consistent, accurate responses to multiple-choice questions across different AI sessions and platforms. The core principle is constraint-by-design: the AI operates within a bounded response space defined by the user's provided options and attached resources.

The "Leave it as is" protocol serves as a safety mechanism. When an AI begins to generate unsolicited explanations or external references, this phrase immediately constrains it back to the provided options. This is particularly important when working with educational assessment platforms where answer accuracy depends on course-specific material rather than general knowledge.

The template is portable and can be pasted into any new AI session to establish consistent behavior. It defines seven operational guidelines covering response format, resource utilization, answer selection, verification, user instruction respect, structured responses, and feedback loops. This ensures that regardless of which AI agent handles the questions, the output format and accuracy standards remain consistent.

Application areas demonstrated include accounting ethics (Sarbanes-Oxley Act, FASB, GAAP), trial balance worksheets, cash flow classification, inventory turnover, weighted average cost method, WACC calculations, and asset turnover ratios.
